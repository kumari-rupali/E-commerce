# 🛍️ Rupali E-Commerce Store

A modern, responsive e-commerce web application inspired by large Indian shopping platforms. Built with React, TypeScript, Vite, Tailwind CSS, Firebase, Zustand, and Stripe-ready checkout integration.

## 🌐 Live Demo

https://saharika.vercel.app

## 💻 Source Code

## ✨ Highlights

- Product discovery and product detail pages
- Persistent shopping cart and wishlist
- Firebase authentication and Firestore integration
- User profiles and orders
- Address management
- Checkout flow
- Responsive desktop, tablet and mobile UI
- Motion-based interactions
- Vercel deployment

## 🧰 Tech Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- Zustand
- React Router
- Firebase / Firestore
- Stripe-ready checkout
- Lucide React
- Motion

## 🚀 Run Locally

```bash
git clone https://github.com/kumari-rupali/E-commerce.git
cd E-commerce
npm install
npm run dev
```

Create `.env.local` using `.env.example` and configure the required Firebase variables before using Firebase-powered features.

## 🏗️ Production Build

```bash
npm run build
npm run preview
```

## ☁️ Vercel Deployment

- Framework: **Vite**
- Build command: `npm run build`
- Output directory: `dist`
- Add the variables from `.env.example` in Vercel Project Settings.

> Stripe secret keys must never be exposed through frontend `VITE_*` variables. Real payment processing should use a secure server/API deployment.
